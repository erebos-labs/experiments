# The shortcut trap, one day later

Open index.html. Run `python3 -B build.py` to rebuild the standalone page, or `python3 -B build.py --check` to reject stale generated bytes without writing. Python 3.10 or later and Node.js 18 or later are the declared command-line baseline. Native browser results and limits are in VALIDATION.json; no older-browser or device guarantee is implied.

`node verify.js` runs 2,424 bounded simulations and inspects 293,506 states. `python3 -B verify_equilibrium.py` compares 162 rational edge-incidence KKT oracle cases with production output. The oracle does not import production formulas; the comparison harness imports the production module. `node test_review.js` checks arithmetic-overflow rejection and bounded trajectories. Reports go to output/. No runtime package installation is needed.

The full synchronous update sends all demand to the cheapest route set from the preceding day. The gradual rule uses a fixed convex-combination share. Ties preserve occupied winning-route proportions, or split equally when none is occupied. The analytic Wardrop allocation is a stationary reference, not an overwritten trajectory. The UI stays within two bounded models; direct API calculations reject non-finite derived arithmetic. Invalid-input claims cover the actual enumerated checks, not every possible JavaScript object.

## Limits and attribution

The deterministic recurrence is an authored teaching adaptation, not a replication of cited stochastic or perception-learning models. It omits queues, heterogeneous beliefs, finite travelers, induced demand and calibration. Fixed points need not attract this rule; smaller constant steps can still chatter. Finite tests do not prove general convergence.

SOURCES.md gives pinpoint primary references. Horowitz and Smith–Wisten are related bibliographic context, not assertions that their detailed formulations were recreated. The Braess coefficients are from equation (3.6), printed p. 448, and the stationary six-unit example from p. 449. PROVENANCE.json records source/fixture identities, actual checks and the tested toolchain. AI assistance is acknowledged; existing copyright and third-party rights apply. No empirical traffic validation, new mathematical discovery or human referee review of this implementation is claimed.

Validation includes python3 -B test_validation.py: stale generated pages, duplicate build tokens and a deliberately wrong equilibrium must fail with and without Python optimization. The chart metric is late-window span, not a test for oscillation. At demand 1 the gradual trace can be monotonic with a larger span than the already stationary synchronous trace. Trace identity has solid/dashed mapping; the chart retains a readable coordinate scale in a keyboard-focusable horizontal scroll region on narrow screens. Negative input flows are rejected; floating-point conservation uses the documented comparison tolerance.

One random-looking card is not enough

The top card tells you only one thing about a deck. It can be almost unpredictable while strong patterns remain in the order of the other cards.

Imagine choosing a random card and rotating an otherwise sorted deck until that card is on top. Every card is equally likely to be first. Yet the circular order never changes: only 52 of the 52! possible orders can appear.

Real riffles mix more than that example. The comparison below asks how much bias remains when you inspect one card, one count, or the entire order. Start at five riffles, then try seven.

Why the second count exposes all the bias in this model

For the ideal binomial-cut shuffle, every permutation with the same number of inverse descents has the same probability. Grouping by that count therefore preserves the whole-deck total variation distance exactly. The first count does not have this property.

With a = 2k, n = 52 and h inverse descents, a particular deck has probability:

P(deck) = binomial(a + n − h − 1, n) / an.

The computation groups permutations using Eulerian numbers, so it never enumerates 52! decks. Integer arithmetic is used until final display rounding.

Addition is hiding here

The visible neighbor-descent count has the same distribution as a carry: choose 52 independent integers from 0 to a − 1, add them, then divide by a and keep the integer part.

For k binary riffles, a = 2k. This is also the outgoing carry after adding the first k binary columns of 52 random numbers, starting with carry 0.

This is an equality of distributions. Reusing a shuffle’s random labels does not generally make the two values equal in each sample.

Established by Diaconis and Fulman; independently checked here by exact small-deck enumeration and a 52-card joint-count identity.

“Seven” depends on the question

At seven ideal riffles the whole-deck distance is 0.334. It crosses 0.25 at eight riffles and 0.10 at nine. “Seven” is a useful landmark in a curve, rather than an exact transition to randomness.

Methods, limits, and primary sources

Start with distinct labels 1–52 in order. An ideal GSR riffle uses a Binomial(52, ½) cut and uniformly random interleaving. Repeated riffles are equivalent in distribution to one a-shuffle with a = 2k. Real hand technique was not measured. Fixed cuts here are still randomly interleaved; they are not deterministic perfect shuffles.

TV is half the sum of absolute probability differences, equivalently the largest absolute probability gap for any event. Separation instead compares relative probabilities of individual orderings. No game-specific fairness or practical prediction claim is made.

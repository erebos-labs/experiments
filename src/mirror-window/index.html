Inspect the small-error evidence

At each point, retune separately to the best central peak. Only the error pattern, correlation and layer count stay fixed. The plot compares thickness error with index error; it sweeps 0.05%–6.4% error amplitude independently of the main error slider.

Open this view to compute the selected pattern.

Axes are logarithmic. A slope near 4 means doubling a sufficiently small error multiplies reflected power by about 16; a slope near 2 means about 4. The fit uses only the first four amplitudes (0.05%–0.4%). A finite-error fit can depart from the limiting power, especially when its leading coefficient is small.

What this model does—and where it stops

H and L are ideal, nondispersive materials with nominal refractive indices 2.3 and 1.45. Each nominal layer has optical thickness n × d = 600 / 4 nm. In the ideal stack, the two central L chunks have the same index and together form a half-wave cavity. Light arrives perpendicular to infinite, perfectly smooth interfaces.

Both orderings use the exact same layer objects, including errors. Thickness errors leave indices fixed; index errors leave physical thicknesses fixed. Mirror-paired errors copy the first half in reverse order. A shared scale error gives every layer the same fractional change.

The central peak is bracketed on 540–660 nm, then refined by minimizing reflected power. Its linewidth is the distance between the nearest half-height crossings. A boundary maximum or missing crossing is flagged rather than called a resolved resonance. The plotted peak has extra samples near the refined wavelength; a coarse chart alone can miss it.

Gaussian spectral averages use adaptive integration with explicit breakpoints around the narrow mode. This is a spectrum calculation, not a time-domain pulse animation. It omits absorption, scattering, oblique incidence, dispersion, nonlinear response, finite beam size, temperature and real fabrication statistics.

The small-error fourth-power result applies to thickness perturbations of this quarter-wave, equal-surroundings family after retuning, generically when its leading coefficient is nonzero. Changing the index or surroundings can remove that special behavior. Mirror symmetry is sufficient for many perfect resonances, but it is not necessary in general.

A separate passive-absorption control illustrates another limit: assigning both ideal materials a common extinction coefficient κ = 0.0001 reduced the 600 nm transmission of the 32-layer stack to 39.81%, compared with 97.19% for 16 layers. These are illustrative constants, not a prediction for any named material. This control is separate from the lossless interactive calculation and the Gaussian bandwidth comparison.

A moved window can look like a broken one.

A measurement at the original wavelength mixes up two effects: the peak moving and the peak getting lower. Retune after adding thickness error, then switch to index error and compare.

A taller peak can pass less light.

More layers make the ideal central window narrower. With a finite spectral width, much of the light falls beside the window. Try 32 layers and a 1 nm spectrum.

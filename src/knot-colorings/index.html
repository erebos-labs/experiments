The deeper blind spot

More Fox labels cannot reveal the Conway knot.

The Conway knot is nontrivial, yet it has exactly q constant Fox colorings and no nonconstant ones, for every integer modulus q ≥ 2. Its Fox counts match an unknot’s.

That conclusion comes from an integer certificate, rather than an exhaustive list of moduli. Knot Atlas supplies the diagram data; Piccirillo’s paper establishes that the Conway knot is not slice, which in particular rules out the unknot.

Why the certificate works

Subtract the label of one arc from every label. That arc now has label 0, and every crossing equation still holds. For the Conway diagram, ten of those equations form a 10 × 10 integer matrix B with determinant −1.

B has an integer inverse, so it is invertible modulo every q. The other ten labels must therefore be 0 too. Before subtraction, the only solutions were constant. The computation uses the Knot Atlas Gauss code and checks B × B⁻¹ = I with exact integers.

A different algebra reveals the knot.
The default order-3 class uses 56 matrix labels with a conjugation rule. This Conway diagram then has 728 colorings: 56 constant and 672 nonconstant. The unknot has only the 56 constant ones. This reproduces Eisermann’s Example 2.18: 13 colorings when one arc’s label is fixed, multiplied by 56.
Each label is a 2 × 2 determinant-one matrix modulo 7, with M and −M identified. These are group labels with a different crossing operation. The controls below verify one stored coloring at a time; the total was computed by exhaustive seed enumeration.
What this comparison establishes
All 11 crossing equations hold for each displayed nonconstant witness. For the default order-3 class, the computation explores 3,136 assignments after fixing one seed arc; simultaneous conjugation gives equally sized fibers for all 56 labels. The result establishes ordinary knottedness. Piccirillo’s work concerns the deeper question of smooth sliceness.
The order-3 class gives 392 colorings for the Kinoshita–Terasaka diagram, although both it and Conway have only constant Fox colorings at every modulus. These counts distinguish the two supplied diagrams as knots.
Within the same group, the order-2 class gives just 21 constant colorings for each knot; the order-7 class gives 360 colorings for each. The latter detects both knots but leaves them tied. The choice of label class matters.

Method, limits and sources
The interactive bench checks every top assignment, propagates labels down the braid, and keeps precisely those whose bottom labels match their top labels. It uses exact integer modular arithmetic, with at most 16 crossings and 9 labels in the controls. Composite moduli are enumerated directly.
This is an implementation of established mathematics. It provides examples and certificates; it does not classify arbitrary knots. The displayed braid sign convention is left-over-right for a positive crossing. The trefoil’s handedness is left unnamed.
A separate bounded check tried conjugation rules on the 6 transpositions of S₄ and the 15 double transpositions of A₅. Both still gave only constant colorings for this Conway diagram. That null result says nothing about all finite quandles or other knot invariants.

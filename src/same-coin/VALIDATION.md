# Validation scope

The standalone Python and Node verifier reproduces public probability values using absorbing-state and weighted-overlap implementations. Source generation is checked against the included HTML.

Browser interaction on this exact HTML previously covered default values, both pattern selectors, bias and horizon controls, invalid/valid sequences, exact fractions and expanded source panels, desktop and a 390×844 browser viewport. These are not physical-phone, screen-reader or cross-engine certifications. Arithmetic tests are distinct from layout checks.

The page uses textContent and created nodes for user input, limits sequence size, and has no automatic external resources, storage, analytics, upload, backend, credentials, random sampling, timer, cookie write or autonomous behavior. It includes an inline CSP. The hosting provider may independently log visits. Primary-source links are ordinary user-initiated navigation.

The mathematical results are established and credited. Checks do not constitute peer review of a new theorem.

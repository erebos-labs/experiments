# Primary sources

- Daniel Felix (2006), *Optimal Penney Ante Strategy via Correlation Polynomial Identities*: https://www.combinatorics.org/ojs/index.php/eljc/article/download/v13i1r35/pdf — suffix/prefix overlaps and fair-coin strategies.
- Joshua B. Miller, *Penney’s Game Odds From No-Arbitrage*, v3: https://arxiv.org/html/1904.09888v3 — race probabilities and mean duration from weighted overlap payoffs.
- Anne-Laure Basdevant, Olivier Hénard, Édouard Maurel-Ségala and Arvind Singh, *On cases where Litt’s game is fair*, v2: https://arxiv.org/html/2406.20049v2 — equal-autocorrelation score symmetry; footnote 1 explicitly identifies the boundary-dependent family used here.

The implementation independently expresses these established ideas. Source publications retain their own rights. No paper body, third-party code, image, font, dataset or other asset is bundled.

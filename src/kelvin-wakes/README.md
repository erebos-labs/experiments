# The wake you measure

An educational explorer of linear deep-water gravity waves generated by a circular Gaussian pressure patch. The geometric Kelvin ray caustic is about 19.47°, while a peak or a chosen threshold can identify a smaller apparent angle. Select height, slope magnitude or absolute Laplacian to compare their angular profiles.

At Fr = 2 the sampled model peaks are 6.375°, 5.625° and 5.125°. They are illustrative model outputs, not ship measurements or a novel discovery. A 20% height threshold can produce disconnected angular bands. Each curve is normalized separately, so their absolute heights or energies cannot be compared from the display.

## Model and reproduction

Use `Fr = U/√(gb)`, `λg = 2πU²/g` and Fourier pressure spectrum `P̂(K) = exp[−K²/(4π²)]`, `K = kb`. `model.mjs` implements the far-field residue integral from Darmon et al., Eq. 2.8, with `t = tan θ`. The Gaussian tail exponent is 30; a phase-step bound chooses composite-Simpson resolution. Derivatives are taken inside the integral. The displayed statistic is the maximum absolute height, gradient magnitude or absolute Laplacian across 49 radii from 10 to 11 λg, with 0.125° angular steps. The source JSON retains the sampling parameters.

```sh
python3 -B src/kelvin-wakes/build.py
node src/kelvin-wakes/verify.mjs
node src/kelvin-wakes/generate.mjs /tmp/kelvin-wave-data
```

Run from the repository root. Generation uses one thread, no packages or network, and takes tens of seconds. Its required output directory avoids overwriting the checked-in dataset by default. Root `build.py` reproduces the self-contained source page and `docs/kelvin-wakes/index.html`. The page itself uses precomputed data and performs no background quadrature.

## Limits

Pure gravity, infinite depth, linear waves, circular Gaussian forcing and a far-field residue approximation; the near-field contribution is omitted. Real hull geometry, finite depth, viscosity, surface tension, currents, nonlinear waves, lighting and camera response are not simulated. Finite-distance tails may extend outside the ray caustic. The high-speed formula is not used as a universal speed law. Sampling and finite-window interference affect the displayed peak, so tenths of a degree are illustrative rather than empirical precision.

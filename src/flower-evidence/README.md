# Does a flower have an ear?

Open index.html for published concentration summaries, a hypothetical cross-group comparison and the limits of the biological claim. It makes no automatic network requests and uses no external assets. The overview is a semantic list of group means and standard errors. Mechanical evidence not established here is labeled unknown; the illustration is not visible movement or an amplitude measurement.

Run `python3 -B test_demo.py`. Eight checks cover arithmetic, fixture parity, the embedded group values, syntax and static resource checks. Python 3.10 or later and an existing Node.js 18 or later are required. The browser target is current evergreen browsers; current browser results and limits are in VALIDATION.json.

Optional raw audit: obtain ExpData.zip from the cited Dryad record. Its identity is 69,019 bytes, MD5 a2a2e6a3252b023fe46ef46b507f1145 and SHA-256 2d870d1c4f909c4eda14baf656d46c441a97a738e8b34337604dd775840fe314. Place it and its three XLSX members in raw-data/. Run `python3 -B test_raw_reanalysis.py` and `python3 -B raw_reanalysis.py raw-data/*.xlsx`. Every parsed member must match the pinned archive byte for byte before the report emits archive provenance. Parsing uses the verified in-memory members. Compressed size, entry sizes/count, XML, rows and columns are bounded; formulas, macros and workbook code are never evaluated.

The reader supports the cited workbooks' sheet1 layout, plus inline strings. It is not a general Excel relationship/worksheet selector. The ordinary optional command skips data-dependent checks when inputs are absent; parser/strict-mode checks still run. Use python3 -B test_raw_reanalysis.py --require-data for evidence validation: it fails if the unbundled pinned archive is absent and runs all raw tests with zero skips when present. Inspect mode parses the verified in-memory bytes too. Full generated raw-summary.json equality and a modified-workbook rejection are checked. Raw inputs are not distributed or automatically downloaded.

## Interpretation

This is not biological replication or mixed-model reconstruction. There is no stable plant identifier for treating deposited rows as independent plants; no new significance tests are supplied. Computed row_naive_se is s/sqrt(row count), not an uncertainty estimate for independent plants; clustering and repeated-measure effects are unknown. Published-caption SE transcriptions remain separately labeled. The volume-weighted concentration proxy has units µL × mass fraction, omits solution density and is not sugar mass. The two endpoints use separate published treatment groups, not paired observations. Fall caption/deposit numerical pairs cross-match opposite labels; the record does not identify the mistaken labeling. No full sound-to-secretion-to-visitor-to-fitness chain is demonstrated.

Primary links and the earlier source-access limits remain separate from generated observations. AI assistance is acknowledged; cited publications retain their rights. Existing copyright terms apply. No new discovery, acoustic/biological validation or human referee review of this implementation is claimed. PROVENANCE.json records the selected fixtures, toolchain and actual checks, not an independent scientific attestation.

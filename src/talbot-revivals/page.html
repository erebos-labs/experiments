Why the return happens—and why it slips

Let X = x/d and let cn be the complex amplitude of diffraction order n. After removing the common carrier, each order rotates at its own rate:

zR = 2d²/λ,   τ = z/zR,   α = λ/d
U(X,τ) = Σ cn exp(i2πnX + iφn)
φnparaxial = −2πτn²
φnscalar = (4πτ/α²)[√(1 − n²α²) − 1]

At τ = 1 the paraxial phase of every integer order completes an integer number of turns. At τ = ½, the factor (−1)n² = (−1)n translates the field by half a period. Here zR always means the full return distance; Berry and Klein use “Talbot distance” for d²/λ, half this value.

The comparison starts at the nominal paraxial return distance. A small distance adjustment can improve the exact scalar overlap. A field containing only orders 0 and ±1 can return exactly at a shifted distance; a broad spectrum generally leaves competing phase errors. The button searches only 0.98 ≤ τ ≤ 1 and reports the best overlap found there.

Small angles can still accumulate a large phase error over a long path. At τ = 1, n = 10 and λ/d = 0.01, that order travels at only 5.74° but slips by 1.579 radians relative to the paraxial prediction. The leading correction is −(π/2)τ(λ/d)²n⁴. This is an established post-paraxial effect, illustrated here by a finite numerical model.

Methods, assumptions and limits
  • 65 Fourier orders, n = −32…32; smooth Gaussian spectral coefficients exp(−2π²σ²n²), with optional phase exp(i2πbn²). The “three orders” input uses c₀ = 1 and c₊₁ = c₋₁ = ¼ before normalization.
  • Infinite periodic transverse field; monochromatic, coherent, scalar forward propagation. All retained orders propagate in the allowed parameter range. There is no finite aperture, evanescent field, polarization, material, loss or measured apparatus.
  • “Exact scalar” means exact dispersion for this finite scalar angular spectrum. It does not mean a full electromagnetic model or exact reconstruction of a physical grating.
  • The phase twins use ±b. Their initial intensities match because their fields are complex conjugates. Their future intensities can differ. This phase is specified across Fourier orders, not directly as a quadratic spatial phase mask.
  • A carpet uses 420 × 254 samples. Curves and the mixture difference use 513 samples across one period. The finite smooth model is not a test of fractal dimension.
  • For a real input at τ = ¼, the two surviving copy weights differ in phase by π/2. Their intensity cross term vanishes, so the phase-free control happens to agree. It fails for other overlapping or complex copies.
  • Changing width, wavelength or spectrum recomputes a bounded static carpet. There is no animation, timer, automatic network request or saved user state.
